# MagicSomethingOther — описание MVP

Godot **4.5**, 2D top-down, кооперативный horde shooter. Этот каталог — контракт архитектуры. Скрипты, сцены и ресурсы игры на этом этапе не создаются.

Когда описание утверждено, реализация собирается по файлам ниже: те же имена классов, деревья сцен, авторитет сервера и стартовые числа.

## Рамки этапа

В описании зафиксированы:

1. Три режима из главного меню при одной серверной модели.
2. До матча общий пул `essence` тратится на характеристики (скорость, выносливость, сила рывка, обзор, здоровье) и на крафт трёх слотов заклинаний.
3. Игрок с рывком, локальной камерой, здоровьем и слотами ЛКМ / ПКМ / СКМ.
4. Заклинание собирается из элемента (огонь, вода, земля, воздух, лёд, свет, молния) и формы (снаряд, область, стена, луч, на себя, вокруг себя, мина). Свет лечит, остальные шесть наносят урон. Доставка всех семи форм описана.
5. Локальные настройки: режим окна, разрешение, VSync, предел кадров, масштаб UI, переназначение клавиш, языки `ru` и `en`.

Дальше по имени, без поведения в этом контракте:

- волны врагов и их ИИ (у игрока уже есть `take_damage` и `heal`, у врага зарезервирован `take_damage` и группа `enemies`);
- отдельные эффекты стихий: горение, замедление, мокрый статус, цепь молнии (id элемента уже хранится);
- сохранение прогресса `essence` между сессиями (бюджет подготовки каждый раз `100`);
- предсказание движения на клиенте;
- список серверов, NAT и пароль лобби;
- пауза уже идущего матча.

## Модель авторитета

Listen Server. Синглплеер — тот же сервер на одном пире, без сокета.

На сервере (`multiplayer.is_server()`): спавн, положение игрока и снаряда, урон, уничтожение, проверка сборки перед матчем. Списание `essence` в черновике подготовки считается теми же формулами; в матч попадает только сборка, которую сервер прогнал заново с бюджета `100`.

Графика, клавиши и язык живут в `user://settings.cfg` и на сервер не отправляются.

Узел игрока принадлежит серверу (peer `1`). Кто им управляет, записано в имени узла: `str(peer_id)`. Этот пир шлёт ввод. Камера включается у узла, чьё имя совпало с `multiplayer.get_unique_id()`.
